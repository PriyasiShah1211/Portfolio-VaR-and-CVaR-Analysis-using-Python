# 🧮 Project Overview 
This project demonstrates the calculation and visualization of portfolio Value-at-Risk (VaR) and Expected Shortfall (CVaR) using Python. It applies both Parametric (Variance-Covariance) and Historical approaches to estimate potential daily losses at 95% and 99% confidence levels. Includes backtesting to validate model accuracy and visual analysis of tail risk exposure using Pandas, NumPy, Matplotlib, and Seaborn.

---

# 🎯 Project Objective
To calculate and visualize daily portfolio Value-at-Risk (VaR) and Expected Shortfall (CVaR) using historical and parametric methods, and perform simple backtesting to evaluate the accuracy of risk estimates.

---

# 🧰 Tools & Libraries
1. Python
2. Pandas, NumPy – data manipulation and computation
3. Matplotlib, Seaborn – data visualization

---

# 💾 Dataset
Used 5–10 assets from different sectors (e.g., AAPL, JPM, TSLA, AMZN, XOM)
